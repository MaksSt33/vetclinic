# Лабораторна робота № 2 — «Лапка»

Комп’ютерна версія сайту за [макетом Figma](https://www.figma.com/design/QMHLRv3P49GmNWXlGBgmnc/Vetclinic?node-id=9-561). Вимоги: [HTML, CSS та Flexbox — модуль 02](https://9.lviv.ua/academy/web-development/html-css-flexbox/).

## Як відкрити

Відкрийте index.html у браузері. Фотографії, іконки та шрифти збережені локально; сторінка працює без інтернету. Основний макет розрахований на 1440 px. Мобільна адаптація належить наступному модулю.

## Структура й семантика

- index.html — шапка, навігація, основні секції, картки, форми та підвал.
- css/style.css — кольори, типографіка, компоненти та розкладка Flexbox.
- css/fonts.css, fonts/ — локальні Inter та Nunito Sans і їхні ліцензії.
- img/ — фотографії, знак логотипа, іконки послуг із Figma та допоміжні SVG.
- preview.png, preview-desktop.png — перевірений вигляд сторінки.

Використано лише HTML і CSS, без JavaScript, фреймворків, Grid, float та табличної розкладки. Є один main і h1, смислові section із заголовками, nav для навігації, article для карток, header і footer. Зображення мають alt та розміри, поля форм — пов’язані label, посилання й поля — видимий стан клавіатурного фокуса.

div дозволений для груп без власного смислового розділу: контейнера ширини, ряду карток, колонки тексту, пари кнопок. Кількість div сама по собі не визначає правильність семантики. Не потрібно замінювати кожен контейнер на section: секція повинна позначати окремий розділ із заголовком.

Відступи коду — два пробіли. У CSS кожна декларація записана окремим рядком, правила розділені порожніми рядками та згруповані за блоками сторінки.

## Звірка з Figma

Параметри прочитані з вихідних шарів Figma. Основний текст — Inter, заголовки — Nunito Sans ExtraBold. Відгуки — Nunito Sans SemiBold, 21 px. Фотографії, знак у шапці та іконки послуг експортовані окремими зображеннями в подвійному розмірі; поверх фотографії першого екрана розміщені справжні HTML-панелі.

Допоміжні SVG у контактному рядку й соціальних посиланнях відтворені окремо.

## Як самостійно звірити відступи

1. У Figma відкрийте фрейм Desktop — 1440. Виділіть потрібний шар, затисніть **Alt** і наведіть курсор на сусідній шар або батьківський фрейм. Показані відстані мають значення в px незалежно від масштабу полотна.
2. Для Auto Layout дивіться праворуч **Gap** та **Padding**; для тексту — шрифт, накреслення, розмір і Line height.
3. Відкрийте сайт у Chrome або Edge, натисніть **Ctrl+0**, **F12**, потім **Ctrl+Shift+M**. У режимі Responsive задайте ширину 1440 px. Якщо звичайна смуга прокрутки займає 15 px, доступна ширина сторінки буде 1425 px. Для точного порівняння 1440 px вмісту збільште ширину перегляду на ширину смуги прокрутки. Перевірити доступну ширину можна в Console: document.documentElement.clientWidth.
4. Інструментом вибору елемента **Ctrl+Shift+C** виберіть відповідний блок. У **Computed / Box Model** дивіться фактичну ширину, висоту, margin та padding. Проміжок **gap** дивіться у батьківському Flexbox-контейнері.
5. Порівнюйте межі текстових блоків і карток, а не відстані між видимими літерами. Шрифт і Line height впливають на положення літер усередині текстового блока.

## Межі лабораторної роботи

Пункт «Ціни» вилучено за вашим побажанням, кнопку першого екрана змінено на «Переглянути послуги». Її ширина відрізняється від макета через довший текст.

Форми дозволяють вводити дані, але не надсилають заявки: серверна обробка не входить до роботи з HTML/CSS. Для зв’язку є телефонні посилання. Адреси профілів клініки й текст політики конфіденційності не надано, тому соціальні посилання ведуть на головні сторінки сервісів, а назва політики показана як текст.
