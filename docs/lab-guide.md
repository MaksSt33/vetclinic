# Пояснення до лабораторних

## Каркас і Flexbox

`header` містить контакти та навігацію, `main` — основні розділи, `footer` — контактні дані й пояснення про навчальну форму. Кожний самостійний розділ має `section` і заголовок. Картки послуг, лікарів, відгуків і пакетів — `article`. `div` використовується для контейнерів ширини й груп розкладки, яким не потрібна власна семантика.

`.container` обмежує ширину та центрує вміст. `display: flex` утворює ряд або колонку. `gap` задає проміжки між дітьми; `padding` — внутрішній відступ блока; `margin` — зовнішній. `flex: 1` дозволяє карткам ділити вільне місце. `align-items: stretch` робить їх рівновисокими, а `margin-top: auto` у кнопки пакета займає вільне місце над нею й вирівнює кнопки внизу.

## Модуль 03: адаптивність

Три основні медіа-запити розташовані після базових правил:

- До 1200 px — менші проміжки, заголовки й гнучкіші колонки.
- До 900 px — перший екран і форма переходять у стовпчик, з’являється мобільне меню.
- До 600 px — мобільна композиція, великі зони натискання, картки й пакети в колонку.

Меню зберігає стан у фрагменті URL: `#site-menu` відповідає CSS `:target`. Порожні GET-форми потрібні тільки для нативних кнопок відкривання й закривання, доступних через Tab, Enter і Пробіл. Контактні форми — інші, вони використовують POST та Formspree. Коли користувач обирає, наприклад, `#doctors`, попередній якір зникає, тому меню закривається. Прихований стан має `visibility: hidden`, тож його посилання не потрапляють у Tab-порядок.

Сам checkbox із прикладу методички не змінюється після натискання на якір. Тому тут використано інший механізм без JavaScript. Компроміс: перше відкриття через GET може перезавантажити документ. Клавіша Esc для цього меню не реалізована; у чек-листі модуля вона не є обов’язковою.

## Модуль 04: медіа

Змістовне фото — це `img` з описом `alt`, шириною й висотою. Декоративне фото під текстом — `background-image` із затемненням. `cover` заповнює блок і може обрізати краї зображення; `object-fit: cover` робить те саме для `img` і `video`.

`picture` підбирає окремий кадр для смартфона. Головне фото має високий пріоритет, а фотографії нижче першого екрана — `loading="lazy"`. WebP стискає фото, WOFF2 — шрифти. Постер відео з’являється, поки кадри ще не завантажені.

Відео має `autoplay`, `muted`, `loop`, `playsinline`: автоматичне відтворення, без звуку, повтор і відтворення всередині сторінки. Перемикач дозволяє приховати рухомий фон та залишити постер. Це приховування, а не програмне керування `pause()`. При `prefers-reduced-motion: reduce` джерело відео не вибирається, а CSS залишає тільки нерухомий фон.

## Модуль 05: форми й таблиця

`label for` пов’язаний з `input id`: натискання підпису переводить фокус у поле. `name` визначає ключ у заявці, `id` — унікальний ідентифікатор у документі. Placeholder дає приклад, але не замінює label. `fieldset` і `legend` об’єднують споріднені поля.

`required` забороняє порожнє поле, `type="email"` перевіряє формат пошти, `pattern` обмежує телефон цифрами й необов’язковим `+`. Текстова довжина обмежується `minlength`/`maxlength`. Браузерна перевірка поліпшує введення; приймання, зберігання й антиспам забезпечує Formspree. `:user-invalid` показує помилку після взаємодії, а не відразу після відкриття порожньої форми.

Таблиця має `caption`, `thead`, `tbody`, заголовки `th` зі `scope="col"` та `scope="row"`. На телефоні гортання з’являється лише всередині `.table-scroll`, а не на всій сторінці. Обгортка доступна з клавіатури й має зрозумілу назву.

## Модуль 06: компоненти

Базовий клас `.price-card` спільний для трьох пакетів, модифікатор `.price-card--recommended` додає виділення. Колір, текст, рамка й бейдж позначають рекомендований пакет без залежності від наведення миші. Він стоїть першим і в HTML, і на екрані, тому візуальний та клавіатурний порядки збігаються.

Кнопки мають звичайний стан, `:hover`, `:focus-visible`, `:active`. Стиль `:disabled` підготовлений для справді недоступних кнопок; робочі кнопки навмисно не вимкнені.

## Модуль 07: рух

`transition` згладжує зміну конкретних властивостей між станами. `transform: translateY` візуально зміщує картку, не пересуваючи сусідні елементи. `@keyframes appear` задає власну одноразову послідовність появи заголовка. Анімації немає потреби запускати нескінченно.

Останній CSS-блок `prefers-reduced-motion` вимикає анімації, переходи та плавне прокручування. Зміст залишається видимим, а меню й форми працюють.

## Модуль 08: Git

`git status` показує зміни. `git add` додає їх у наступний знімок, `git commit` зберігає цей знімок локально, `git push` відправляє історію на GitHub. Це різні кроки. `.gitignore` виключає локальні дослідження, кеші й тимчасові файли. `.gitattributes` узгоджує закінчення рядків. `.nojekyll` дозволяє GitHub Pages публікувати звичайні статичні файли.

Звичайне оновлення після зміни сайту:

```sh
git status
git add index.html css/style.css
git commit -m "Уточнити текст і відступи форми запису"
git push
```

GitHub Pages публікує гілку `main`, папку `/ (root)`. Посилання на ресурси відносні, тому працюють у підпапці `/vetclinic/`.

## Як порівняти з Figma

Виділіть шар і затисніть Alt для відстані до сусіда. У браузері відкрийте F12 → вибір елемента → Computed / Box Model. Порівнюйте межі блоків, а не видимі літери. Для `gap` вибирайте батьківський Flexbox-контейнер. Враховуйте ширину смуги прокрутки: ширину вмісту можна прочитати через `document.documentElement.clientWidth`.
