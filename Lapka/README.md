# Лапка — навчальна версія модулів 02–08

Адаптивний сайт ветеринарної клініки на HTML і CSS. Основу модулів 02–04 доповнено формами, таблицею, тарифними картками й анімаціями. Мобільне меню використовує checkbox.

- [Навчальна версія на GitHub Pages](https://maksst33.github.io/vetclinic/Lapka/)
- [Репозиторій](https://github.com/MaksSt33/vetclinic)
- [Макет у Figma](https://www.figma.com/design/QMHLRv3P49GmNWXlGBgmnc/Vetclinic?node-id=9-561)
- [Чек-лист модулів 05–08](checklist-05-08.md)
- [Пояснення бургер-меню](menu-checkbox.md)

Для локального перегляду відкрийте цю папку через Live Server. `index.html` містить розмітку, `css/style.css` — стилі, `css/fonts.css` — підключення шрифтів. Папки `fonts`, `img` і `video` містять локальні ресурси.

Обидві форми надсилають навчальні заявки через Formspree. Для тесту вводьте вигадані дані. Ціни пакетів демонстраційні; форма не бронює справжнього прийому.

Фотографії та частина іконок узяті з макета. Ілюстративне відео: Mikhail Nilov, [Examining a Dog / Pexels](https://www.pexels.com/video/examining-a-dog-7469712/), [ліцензія](https://www.pexels.com/license/). Ліцензії Inter і Nunito Sans є в `fonts/`.
