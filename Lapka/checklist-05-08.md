# Перевірка модулів 05–08

Дата перевірки: 12.11.2026. Цей документ стосується версії з папки `Lapka`.

## [05 — HTML-форми та таблиці](https://9.lviv.ua/academy/web-development/forms-tables/)

- [x] Обидві форми мають `action` на Formspree та `method="post"`. Поля згруповані у `fieldset` із `legend`; видимі поля мають підписи через `for` і `id`, усі поля, які надсилаються, мають `name`.
- [x] Є текстове, телефонне, email-поле, дата, `select` і `textarea`. Обов’язкові поля мають `required`; перевірено відхилення порожньої форми, некоректного телефону й email.
- [x] Усі `id` унікальні. Поля успадковують шрифт і мають висоту щонайменше 48 px; є контур фокусу, стиль помилки та наведення на кнопку. Кнопки описують, яку заявку надсилають.
- [x] Основну форму заповнено та надіслано з клавіатури в Chrome з перехопленням запиту. Для обох форм перевірено метод POST та дані запиту. Окремий реальний тест Formspree повернув `ok: true`.
- [ ] Підтвердити, що новий тестовий лист надійшов на пошту власника.
- [x] Графік прийому оформлено як таблицю даних із `caption`, `thead`, `tbody`, заголовками рядків і стовпців. На вузькому екрані вона прокручується у своїй області, зокрема стрілками після фокуса через Tab. Контакти й години роботи є текстом у підвалі.

## [06 — UI-компоненти й ціни](https://9.lviv.ua/academy/web-development/ui-components/)

- [x] Кольори, шкала відступів, радіуси нових компонентів і спільна тінь задані змінними у `:root`. Відступи макета (`padding`, `margin`, `gap`) приведені до кроку 8 px. Службовий `margin: -1px` візуально прихованих елементів не є відступом макета.
- [x] Спільні класи `.btn` і `.card` перевикористані. Є контурний варіант кнопки й стани `:hover`, `:focus-visible`, `:active`.
- [x] Три пакети з назвами, цінами у гривнях, опціями й діями. Рекомендований пакет виділено рамкою і текстовою позначкою. Кнопки переводять до поля вибору пакета.
- [x] На широких екранах картки мають однакову висоту, а кнопки вирівняні внизу через `margin-top: auto`. До 900 px картки стоять стовпчиком, рекомендована перша. Фон змінюється при наведенні та коли фокус усередині картки.

## [07 — CSS-анімації](https://9.lviv.ua/academy/web-development/css-animation/)

- [x] Три прийоми: плавний стан кнопки, зсув картки через `transform`, поява бейджа через `@keyframes badge-arrive`.
- [x] `transition` задані на базових селекторах, властивості перелічені явно. Переходи тривають 200 мс, поява бейджа — 360 мс. Рух не змінює розкладку, CSS-анімації не повторюються нескінченно.
- [x] У Chrome перевірено `prefers-reduced-motion`: переходи, поява бейджа й рух карток вимикаються, замість фонового відео лишається постер.
